Без установки: общий Go-интерфейс работает в WebAssembly. Доступны ввод, клики, клавиатура и прокрутка. На телефоне — автоматический масштаб, кнопки «− / Вписать / +» и сенсорное переключение разделов. Чат локальный, настройки dsh — демонстрационный снимок без подключения к серверу.

Go-прототип с настройками dsh — 0.2.0-preview.5

Прототип на Bubble Tea: боковая навигация, панель разговора, отдельное поле сообщения, история и прокрутка. Мышь: клики по разделам и локальному черновику, фокус поля ввода, прокрутка колесом под указателем. Tab — разделы, ↑/↓ — выбор, Esc — возврат в чат с сохранением черновика. Флаг --no-mouse отключает захват мыши для обычного выделения текста. Разделы «Настройки dsh» и «Настройки TUI» разделены. Сведения о клиенте доступны независимо от подключения. Настройки работающего dsh доступны только для чтения. Задайте URL входа через DSH_TUI_URL или --url. В настройках: ←/→ — раздел, r — обновить; при ошибке сохраняется последний снимок. Секреты скрыты. Чат пока локальный. Node.js для самого Go-клиента не нужен; работающему dsh нужен Node.js 24.9+.

Экспериментальный Go-клиент: чат пока остаётся локальным черновиком. Установку и запуск dsh, потоковый чат и остальные функции переносим постепенно. Для чтения настоящих настроек в Linux-клиенте нужен URL входа уже работающего dsh.
