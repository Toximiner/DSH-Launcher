DSH Launcher TUI

Первый Go-прототип — 0.2.0-preview.1

Отдельный небольшой прототип на Bubble Tea: ввод, история, прокрутка и выход. Пока без подключения к dsh. Node.js для этого прототипа не нужен.

  • Linux amd64: отдельный исполняемый файл
  • Linux arm64: отдельный исполняемый файл
  • Возможности первого этапа · SHA-256

Рабочая JS-версия

Временная страница загрузки экспериментальной терминальной версии 0.1.0.

Для локального запуска с dsh нужен Node.js 24.9+ с npm.

Установить через npm

npm install -g https://toximiner.github.io/DSH-Launcher/dsh-launcher-tui-0.1.0.tgz
dsh-launcher-tui

Если dsh отсутствует, приложение предложит /install — установку в каталог текущего пользователя без sudo. /cancel отменяет установку.

Готовые пакеты

  • Debian / Ubuntu: .deb — требует системный пакет nodejs 22+; для самого dsh нужен Node.js 24.9+.
  • npm: .tgz — подходит в том числе для Node.js через nvm.
  • Контрольные суммы SHA-256
