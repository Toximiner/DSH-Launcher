DSH Launcher TUI

Go-прототип с настройками dsh — 0.2.0-preview.4

Прототип на Bubble Tea: боковая навигация, панель разговора, отдельное поле сообщения, история и прокрутка. Мышь: клики по разделам и локальному черновику, фокус поля ввода, прокрутка колесом под указателем. Tab — разделы, ↑/↓ — выбор, Esc — возврат в чат с сохранением черновика. Флаг --no-mouse отключает захват мыши для обычного выделения текста. Теперь доступны настройки работающего dsh только для чтения. Задайте URL входа через DSH_TUI_URL или --url. В настройках: ←/→ — раздел, r — обновить; при ошибке сохраняется последний снимок. Секреты скрыты. Чат пока локальный. Node.js для самого Go-клиента не нужен; работающему dsh нужен Node.js 24.9+.

Рабочая JS-версия

Временная страница загрузки экспериментальной терминальной версии 0.1.1.

Для локального запуска с dsh нужен Node.js 24.9+ с npm.

Установить через npm

npm install -g https://toximiner.github.io/DSH-Launcher/dsh-launcher-tui-0.1.1.tgz
dsh-launcher-tui

Если dsh отсутствует, приложение предложит /install — установку в каталог текущего пользователя без sudo. /cancel отменяет установку.

Во время установки видны анимированный индикатор, этап, время и счётчик завершённых загрузок npm. Общий процент не показывается, поскольку полный объём заранее неизвестен.

При установленном клиенте и Node.js 22 можно временно запустить его под Node.js 24: npx --yes --package=node@24 --call 'dsh-launcher-tui'.

Готовые пакеты

  • npm: .tgz — подходит в том числе для Node.js через nvm.
