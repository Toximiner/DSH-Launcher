Go TUI: маркет и сессии — 0.2.0-preview.7

Прототип на Bubble Tea: боковая навигация, панель разговора, отдельное поле сообщения, история и прокрутка. Мышь: клики по разделам и локальному черновику, фокус поля ввода, прокрутка колесом под указателем. Tab — разделы, ↑/↓ — выбор, Esc — возврат в чат с сохранением черновика. Флаг --no-mouse отключает захват мыши для обычного выделения текста. Разделы «Настройки dsh» и «Настройки TUI» разделены. Сведения о клиенте доступны независимо от подключения. Настройки работающего dsh доступны только для чтения. Задайте URL входа через DSH_TUI_URL или --url. В настройках: ←/→ — раздел, r — обновить; при ошибке сохраняется последний снимок. Секреты скрыты. Подключение сессии: --session ID или --new. Режимы: /mode default|plan|goal, /goal <задача>. --start запускает dsh и предлагает установить dshmarket в профиль. Раздел «Маркет» или /market: каталог, поиск, установленные пакеты и подтверждаемые установка/обновление/удаление. Чат пока локальный. Node.js для самого Go-клиента не нужен; работающему dsh нужен Node.js 24.9+.

  • Linux amd64: отдельный исполняемый файл
  • Linux arm64: отдельный исполняемый файл
  • Возможности прототипа · SHA-256

Экспериментальный Go-клиент: чат пока остаётся локальным черновиком. Установку самого dsh, потоковый чат и остальные функции переносим постепенно. Режимы сессии и предустановка маркета доступны в Linux-клиенте. Для чтения настоящих настроек в Linux-клиенте нужен URL входа уже работающего dsh.
