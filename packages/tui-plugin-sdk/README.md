# TUI plugin SDK

**Русский** | [English](README.en.md)

Минимальный контракт `dsh-tui-panel/v1` для нативного TUI. Использует существующие
`commands/list` и `commands/execute`: панель возвращается как JSON в `result.text`.
Новые серверные endpoints и отдельный Go-экран для каждого плагина не нужны.
SDK пока распространяется исходниками из этого репозитория.

`registerPanel(ctx, {name, description, render, actions})` регистрирует команду
открытия панели и команды действий `name-suffix`. `render(invocation)` возвращает:

- `title`, `fields`: поля `string`, `integer`, `boolean`, `enum`; `id`, `label`,
  `required`, `default`, `choices` для перечисления;
- `actions`: `label` и `command` в пространстве имён плагина;
- `status`: пары `label`/`value`;
- `tables`: `title`, `columns` и строковые `rows`.

Примеры: [greeting.mjs](examples/greeting.mjs) и [counter.mjs](examples/counter.mjs).
Чтобы проверить пример, добавьте в `cordis.patch.yml` своего тестового профиля:

```yaml
- insert:
    - id: tui-greeting-example
      name: /absolute/path/to/DSH-Launcher/packages/tui-plugin-sdk/examples/greeting.mjs
```

После перезапуска dsh откройте `/commands`, найдите `tui-greeting` и подтвердите
открытие. ↑/↓ выбирают поле или действие; Enter редактирует строку/число,
Space переключает логическое поле, ←/→ — перечисление. Действие всегда требует
отдельного подтверждения. Esc отменяет правку/подтверждение и сохраняет форму;
F5 перечитывает каталог команд. Данные и подписи плагина не переводятся клиентом.

Пределы v1: JSON до 64 КиБ; до 20 полей, 8 действий, 20 статусов, 4 таблиц
по 200 строк × 10 колонок. Ввод — до 16 КиБ, отдельное поле — до 4096 байт;
целые числа ограничены точным диапазоном JavaScript. Неизвестная версия или тип
поля отклоняется. HTML/JavaScript и произвольные RPC-методы не исполняются.
Секретные поля не входят в v1: для ключей используйте сервис credentials dsh.
SDK повторно проверяет вход на сервере; обработчик отвечает за права,
конкурентные изменения и атомарность своей предметной операции. Команды действий
не записывают rawInput в журнал команд. Обрыв связи не вызывает автоматический повтор.

Оба примера проверяются через настоящий dsh в `real_workbench.py`. Состояние
примеров хранится только в памяти; это демонстрации контракта, не хранилища данных.
